# vr-room
My first WebXR room

## Кресло

Вместо стула из шести примитивов загружается `polyhaven-armchair-01.glb`.
Модель и её текстуры находятся в одном GLB-файле; внешние загрузчики и CDN
для кресла не нужны. Масштаб — 1:1 (примерно 85 × 77 × 107 см).
Кресло стоит на полу в прежнем месте стула и обращено к стартовой позиции игрока.

Локальный `aframe.min.js` и код управления сохранены:

- левый стик — движение относительно направления взгляда;
- правый стик — поворот на 30° с возвратом стика в нейтраль перед следующим поворотом;
- на компьютере — WASD и обзор мышью.

## Запуск

Разместите все четыре файла проекта рядом на HTTPS-хостинге, например GitHub Pages.
Для локального просмотра можно запустить `python -m http.server 8000`
в папке проекта и открыть `http://localhost:8000/`.
Открытие `index.html` через `file://` не подходит для загрузки GLB.
Для входа в WebXR с гарнитуры используйте HTTPS-адрес сайта.

## Резервная версия

Исходная версия со старым стулом доступна в файле `v0.1.html` рядом с `aframe.min.js`. Оригинальный тег `v0.1` сохранён в исходном репозитории `prutikof-prog/vr-room`.

## Проверка изменения

В Edge проверены загрузка GLB и встроенных текстур, положение модели на полу,
движение вперёд и вбок, мёртвая зона левого стика, повороты обоими направлениями
и отсутствие повторного поворота при удержании правого стика.
События контроллеров имитировались в браузере; проверка на физической
гарнитуре Quest остаётся отдельным шагом.
